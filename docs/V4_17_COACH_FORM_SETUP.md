# PickleStart V4.17｜教練自行申請表單與人工上架 SOP

本功能定位：**免費資訊目錄**。PickleStart 不安排課程、不替學員聯絡、不收款、不處理預約或雙方糾紛。

## 1. 先建立一張自己的 Tally 表單

1. 到 https://tally.so 登入自己的帳號並建立表單，名稱建議：「PickleStart｜匹克球教練免費刊登／修改／下架申請」。
2. 依下列欄位設定（括號為建議是否必填）；記得讓修改／下架者可以跳過新刊登才需要的欄位，或將表單拆成兩張，之後更新網站表單連結。
3. 在 Tally 表單設定中連接你自己控制的 Google Sheets。試送一份**假的內部測試提交**檢查能否收到，不要公開測試教練。
4. 表單應提供防濫用設定（可用時啟用 CAPTCHA、驗證和通知），只開放授權的人存取試算表。
5. 完成個資告知與授權勾選後才公開表單；不要把 Tally 試算表分享成「擁有連結的人都可以看」。

### 表單欄位範本（可以直接複製題目）

| 題目 | 類型 | 填寫與公開規則 |
|---|---|---|
| 申請類型 | 單選、必填 | 新增刊登／修改資料／申請下架 |
| 原刊登名稱或個人頁網址 | 短文字 | 修改、下架時必填，請人工核對身分 |
| **聯絡 Email（僅供刊登管理）** | Email、必填 | **不得公開在網站或程式碼** |
| 教練公開顯示名稱 | 短文字 | 新增時必填，僅公開這個名稱 |
| 教學縣市（可複選） | 多選 | 新增時必填 |
| 常授課的行政區 | 短文字 | 新增時必填，避免填入家庭地址 |
| 適合程度 | 多選 | 零基礎／初學／進階／競技 |
| 教學方式 | 多選 | 一對一／雙人／團體 |
| 教練介紹 | 長文字 | 建議 50–200 字，不要寫個人隱私 |
| 教學經驗／證照 | 長文字、選填 | 平台預設標為「教練自述」 |
| Instagram 公開個人頁網址 | URL、選填 | 必須是完整 https://instagram.com/... 網址 |
| Facebook 公開專頁或個人頁網址 | URL、選填 | 必須是完整 https://facebook.com/... 網址 |
| **LINE 加好友／官方帳號網址** | URL、選填 | 完整 https://lin.ee/... 或 https://line.me/ti/p/... 網址；**不要要求填電話號碼** |
| 公開介紹照片 | 檔案上傳、選填 | 必須有本人／著作權人提供之公開授權；不要附含其他未同意者之照片 |
| 資料刊登與照片授權 | 必填核取方塊 | 新增刊登者須明確同意公開上面指定欄位與本人提供的社群連結 |
| 隱私告知與服務範圍 | 必填核取方塊 | 詳見下一段範本，保留提交日期和同意紀錄 |

**公開社群聯絡方式 IG、FB、LINE 任選至少一項。** Tally 若不能方便設條件驗證，請人工審核時確認。

### 建議放在表單前的告知文字（需依你的實際管理方式確認）

> 本表單由 PickleStart Taiwan 蒐集教練自行提供的資訊，目的僅為審核、刊登、更新及移除教練目錄。公開資訊限教練同意的顯示名稱、教學地區、程度、方式、自我介紹、社群聯絡連結及經授權照片。管理用 Email 和表單同意紀錄不會公開。資料由 Tally 及連接的 Google Sheets 保存，僅管理人員使用；保留及刪除方式依網站的個資說明與實際服務設定處理。教練可以透過本表單申請更正或下架。提交不代表保證刊登。PickleStart 僅提供資訊展示，不參與課程安排、價格協商、付款或雙方爭議。

以上是可修改的營運文案，不是法律意見。正式上線前請核實你實際使用的第三方工具、聯絡管道、資料保留政策，並更新網站隱私說明以載明控制者聯絡途徑、蒐集目的、資料類別、處理利用、當事人權利與行使方式等應告知事項。

## 2. 將自己的 Tally 網址接到網站（不需要手改程式）

建立並發布表單後，複製形如 `https://tally.so/r/ABC123` 的網址，在 **專案根目錄** 執行：

```powershell
python "$HOME\Downloads\PickleStart_V4_17_Coach_Directory\set_coach_form.py" --check --url "https://tally.so/r/你的表單代碼"
python "$HOME\Downloads\PickleStart_V4_17_Coach_Directory\set_coach_form.py" --apply --url "https://tally.so/r/你的表單代碼"
```

此動作只更新 `src/data/coach-form.ts`；執行後需重新 build / commit / push 才會出現在正式站。若尚未設定，網站會明確顯示「申請表單建置中」，不會出現無效的投稿按鈕。

## 3. 人工審核與刊登流程

- 收到 Tally 提交後，核對申請者是否願意公開資料、公開社群網址是否真正指向他們的帳號；如證照未查證不可寫成「官方認證」。
- 匯出公開欄位後才更新 `src/data/coaches.ts`，**不要複製 Email、電話、Tally 回應全文或同意紀錄進公開程式庫**。
- `approved` 必須為 `true` 且 `active` 為 `true` 才會上架；缺少有效公開社群連結也不會顯示。
- `id` 需唯一、英數和連字號，例如 `chen-coach-taipei`；照片需經同意存入 `/public/images/coaches/`，使用壓縮過的 jpg/png/webp。教練可以不提供照片。
- 記錄 `lastConfirmed` YYYY-MM-DD。建議定期（例如每 90 天）請教練主動確認，長時間未確認可暫時下架。
- 想修改或下架時，先透過管理用 Email 或既有聯絡管道人工核對申請者；設定 `active: false` 或刪除紀錄，重新部署；需要的時候保留更正工作紀錄（不放公開 Git）。

### 公開名單樣板（僅文件示範，**不是已刊登教練**）

```ts
{
  id: "example-coach-taipei",
  approved: true,
  active: true,
  displayName: "【請替換】教練公開名稱",
  cities: ["臺北市"],
  teachingAreas: ["臺北市中山區"],
  levels: ["零基礎", "初學"],
  formats: ["一對一", "團體"],
  introduction: "【請替換】經本人授權之公開介紹",
  lastConfirmed: "2026-10-24",
  instagram: "https://www.instagram.com/yourcoach/",
  line: "https://lin.ee/YOURCODE"
}
```

正式網站從 0 筆公開名單開始，這筆範例**不會進入網站**。教練可提供 IG、FB、LINE 一個或多個網址，不必都有。

## 4. Google 索引與追蹤

- 沒有真實教練時，`/coaches/` 顯示募集空狀態，並 `noindex,follow`，避免空白名錄出現在搜尋結果。第一筆合格教練公開後恢復 `index,follow`。
- 每位符合條件的教練才產生 `/coaches/<slug>/` 個人頁。不會替全部 22 縣市製作空白頁。
- GoatCounter 記錄的是 `coach_contact_clicked` 加上公開的教練 slug 和聯絡平台 IG/FB/LINE，**不會追蹤完整 URL、Email、LINE ID**。
- 平台不替學員傳遞任何訊息，點擊後直接打開教練自己的外部社群頁面。
